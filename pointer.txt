Pointer is one of the derived secondary datatype which holds the address ofanother variable through which we can access data indirectly...



syntax :

        datatype *variable_name;

example :

        int *p;


if pointer is holding an unknown address or garbage address, such pointers are called as wild pointers.

Size of pointer is os dependent, if os is 64 bit then the size of pointer is 64 bit.

irrespective of type of a pointer size of the pointer variable is fixed.

pointer holds address, addresses are generated by os.

If os is 64 bit pointer size is 8 bytes if os is 32 bit pointer size is 4 byte.

Syntax for pointer initialisation

	datatype *variablename = address;

	eg: 
	
		int *p = &i;

while we are dealing with pointers, 2 points we need to take care 

-> p = address

-> *p = value
